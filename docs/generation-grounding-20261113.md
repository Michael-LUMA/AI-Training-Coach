1. 实时模型输入增加服务端从已校验事件换算的 `display_events`：速度3.6、本次均速20.7分别绑定当前与本次均值，不能借历史或把均速粗略念成21。
2. HR漂移明确同次相近速度的参考心率，不是目标心率；上下限事件不提供活动总时长作为越限持续时间。
3. 骑后 few-shot 与可信提示要求跨维度关系及落点，禁止猜测意图；保留已审核 #7、#10，不用医疗/体感/效果断言换取新鲜感。
4. 新增“想休息/刻意/更注重”等无记录意图的拒绝规则。口语“多爬/少爬/爬了”纳入爬升维度，但保留正确单位、双维数字、同句及±15字要求，跨分号借据仍拒绝。
5. 逐条审查 v4 发现自动核验也会放过“条件相同/表现一致”的泛化；最终代码增加拒绝与正反回归。只允许说明已记录的数据一致，不等于环境或整体表现一致。

没有新增依赖、升级模型、改数据库/身份/UI；私测门禁保留，原始GPS不上云，前方爬坡预告关闭。
