# Mark L3 × L2 五人盲评执行协议（V2）

日期：2026-11-12。对象：能理解骑行记录的5位骑行者；本次是合成场景话术验证，不是真实路测、医疗验证或市场规模证明。

## 门禁

- 仅当真实 qwen-max 的20次独立生成全部通过生产核验，且A为纯事实、B含有据推断时，生成参与者材料。拒稿不以模板冒充模型成功，也不挑掉失败场景。
- 样本A使用M7时冻结的L2提示词，另过原严格禁止词与数字检查；双方共用当前数字核验中的词汇消歧修复（“一样”“一些”“什么”不当作数字），不是逐位复现旧核验器。B使用当前L3生产提示词和核验链。同一事实、模型、来源标签、200字上限，不改TTS、不为B挑更好的声音。
- 同一场景中的A/B只在主持人总表保存。参与者只拿自己的P1至P5评分表，不看生成报告、源代码、规则、主持人密钥或其他人的表。
- 没有真实模型数据或评分空白时，不宣布L3获得用户认可，不进入L4。自动核验是句法/数字约束，不是语义正确性证明。

## 10组场景

平均心率下降、上升；记录时长增加；心率相同时记录更久；记录缩短；缺心率；数值相近；小数心率；两组连续历史。均明确标记合成演示。未伪装用户真实心率、骑行或效果。

## 主持人操作（约每人15–20分钟）

1. 找5位骑行者，编号P1–P5。不收集姓名、电话、健康病史；自愿参与，可随时退出。
2. 各发其对应的 `骑行者P*_评分表.csv`。每人10对、合计20条；顺序、每对左右位置独立随机。
3. 对每一对，用同一种声音、同样语速/音量朗读两条话术（或用同一个既有TTS声音播放）。不要告诉参与者“新版更智能”、不要解释哪个是A/B。此次材料是文本；未另做TTS音质对照或真人骑行听觉验证。
4. 每人先独立听完并评分，再讨论。允许重听，但两条给予相同机会。不要在骑行途中操作表格。
5. 保存原始评分表，不覆盖空白模板。主持人最后才用密钥解盲。

## 字段填写

| CSV字段 | 含义 | 取值 |
|---|---|---|
| pair_id | 匿名题号 | 不改 |
| slot1_text / slot2_text | 先/后听的话术 | 不改 |
| companionship_1 / _2 | 像有人在陪我 | 整数1–5，越高越好 |
| continue_choice | 更想继续听哪个 | `1` / `2` / `either` / `neither` |
| understands_1 / _2 | 让我觉得“懂我” | 整数1–5，越高越好 |
| coach_1 / _2 | 像真实教练 | 整数1–5，越高越好 |
| notes | 为什么不想听/哪里误解 | 可空 |

明确引导：“不是判断哪条词更高级，而是你愿不愿意长期听，哪处让你感觉理解了记录，哪处像空话或误解。”不要求参与者认同任何推断。

## 固定过线标准（先定再看结果）

每人10对，5人共50个配对判断。按主持人密钥把slot映射回A/B：

1. **想继续听B比例 = 明确选中B的配对次数 ÷ 50 ≥60%（至少30次）。** either/neither计入分母、不算B胜；不得剔除不利场景。
2. **懂你均分差 = B的50条懂你分数平均值 − A的50条平均值 >1.0分。** 恰好1.0不通过。
3. 两项必须同时过线。陪伴感、像教练为辅助维度，不代替主指标。
4. 缺人、缺题、非整数评分或选择值不合法：结果“不完整”，补齐或按原协议重测；不填默认分、不估算、不把同一人重复评测当新样本。
5. 同时报每位骑行者的结果、各场景结果和either/neither数量；50次判断来自同5人，不是50个独立用户，不能据此宣称市场验证或统计显著。

## 未通过怎么做

- 指出失败集中在哪些场景：空泛套话、推断无用、缺数据不诚实、太长、听不懂数字等。
- 对已确认的问题做定向修复；改变提示词/样本需保留旧版本和失败记录，重新完整生成并做新一轮盲评，不拼接“最好的一句”。
- 不把“数字过核验”当成“推断正确”。如果把更低心率说成身体更轻松、把更长时长说成更健康，应记录为语义失误，即使自动检查通过。
